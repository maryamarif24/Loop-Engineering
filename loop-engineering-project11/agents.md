# Loop Engineering: Project 11 - Agents

This project demonstrates loop engineering concepts using OpenCode.

## Key Agents

- **Maker**: Creates the priority rules, retry policy, and validation criteria (designs the item network, priority assignments, retry strategy, and validation strategy)
- **Checker**: Reviews the priority ordering, retry outcomes, validation results, and failure handling for correctness and fairness
- **Loop Runner**: Executes the validation queue traversal, manages item processing order, retry attempts, and validation checks
