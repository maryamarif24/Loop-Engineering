# Loop Engineering: Project 10 - Agents

This project demonstrates loop engineering concepts using OpenCode.

## Key Agents

- **Maker**: Creates the priority rules and retry policy (designs the item network, priority assignments, and retry strategy)
- **Checker**: Reviews the priority ordering, retry outcomes, and failure handling for correctness and fairness
- **Loop Runner**: Executes the retry queue traversal, manages item processing order, and retry attempts
